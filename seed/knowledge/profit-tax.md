# ອາກອນກຳໄລ ຂອງ ວິສາຫະກິດ

ອາກອນກຳໄລ ແມ່ນ ອາກອນ ທີ່ ເກັບ ຈາກ ກຳໄລ ສຸດທິ ຂອງ ນິຕິບຸກຄົນ ທີ່ ດຳເນີນ ທຸລະກິດ ຢູ່
ສປປ ລາວ. ຖານ ຄິດໄລ່ ແມ່ນ ກຳໄລ ທາງ ບັນຊີ ທີ່ ໄດ້ ປັບປຸງ ດ້ວຍ ລາຍການ ທີ່ ກົດໝາຍ ອາກອນ
ບໍ່ ອະນຸຍາດ ໃຫ້ ຫັກ.

## ອັດຕາ ອາກອນກຳໄລ

ອັດຕາ ມາດຕະຖານ ຂອງ ອາກອນກຳໄລ ແມ່ນ 20 ສ່ວນຮ້ອຍ ຂອງ ກຳໄລ ກ່ອນ ອາກອນ ທີ່ ໄດ້
ປັບປຸງ ແລ້ວ. ບາງ ກິດຈະການ ທີ່ ໄດ້ຮັບ ການສົ່ງເສີມ ການລົງທຶນ ອາດ ໄດ້ຮັບ ອັດຕາ ຫຼຸດຜ່ອນ
ຫຼື ການຍົກເວັ້ນ ຕາມ ໃບອະນຸຍາດ ການລົງທຶນ ຂອງ ຕົນ.

| ປະເພດ ຜູ້ເສຍອາກອນ | ອັດຕາ ຕົວຢ່າງ |
| --- | --- |
| ນິຕິບຸກຄົນ ທົ່ວໄປ | 20% |
| ກິດຈະການ ທີ່ ໄດ້ຮັບ ການສົ່ງເສີມ ການລົງທຶນ | ຕາມ ໃບອະນຸຍາດ |
| ວິສາຫະກິດ ຂະໜາດ ນ້ອຍ ທີ່ ເສຍ ແບບ ເໝົາ | ຕາມ ອັດຕາ ເໝົາ |

## ຖານ ຄິດໄລ່ ອາກອນກຳໄລ

```
ກຳໄລ ທາງ ອາກອນ = ກຳໄລ ທາງ ບັນຊີ ກ່ອນ ອາກອນ + ຄ່າໃຊ້ຈ່າຍ ທີ່ ຫັກ ບໍ່ ໄດ້ − ລາຍຮັບ ທີ່ ຍົກເວັ້ນ
ອາກອນກຳໄລ = ກຳໄລ ທາງ ອາກອນ × ອັດຕາ ອາກອນ
```

ຕົວຢ່າງ: ກຳໄລ ທາງ ບັນຊີ ກ່ອນ ອາກອນ 500000000 ກີບ, ຄ່າໃຊ້ຈ່າຍ ທີ່ ຫັກ ບໍ່ ໄດ້
30000000 ກີບ. ກຳໄລ ທາງ ອາກອນ = 530000000 ກີບ ແລະ ອາກອນກຳໄລ =
530000000 × 20 / 100 = 106000000 ກີບ.

## ຄ່າໃຊ້ຈ່າຍ ທີ່ ຫັກ ບໍ່ ໄດ້

ຄ່າໃຊ້ຈ່າຍ ຕໍ່ໄປ ນີ້ ຕ້ອງ ບວກ ຄືນ ເຂົ້າ ກຳໄລ ຕອນ ຄິດໄລ່ ອາກອນ:

- ຄ່າໃຊ້ຈ່າຍ ທີ່ ບໍ່ ມີ ໃບເກັບເງິນ ຫຼື ເອກະສານ ຫຼັກຖານ ຖືກຕ້ອງ.
- ຄ່າໃຊ້ຈ່າຍ ສ່ວນຕົວ ຂອງ ເຈົ້າຂອງ ຫຼື ຄອບຄົວ ທີ່ ບໍ່ ກ່ຽວກັບ ທຸລະກິດ.
- ຄ່າປັບໃໝ ແລະ ດອກເບ້ຍ ປັບໃໝ ຈາກ ການລະເມີດ ກົດໝາຍ.
- ຄ່າຫຼູ້ຍຫ້ຽນ ສ່ວນ ທີ່ ເກີນ ອັດຕາ ທີ່ ກົດໝາຍ ອາກອນ ກຳນົດ.
- ເງິນສຳຮອງ ແລະ ຄ່າເຜື່ອ ທີ່ ຍັງ ບໍ່ ເກີດ ຂຶ້ນ ຈິງ.

## ການ ຍື່ນ ແລະ ຊຳລະ

ວິສາຫະກິດ ຕ້ອງ ຊຳລະ ອາກອນກຳໄລ ລ່ວງໜ້າ ເປັນ ງວດ ໃນ ລະຫວ່າງ ປີ ແລ້ວ ຍື່ນ ໃບແຈ້ງ
ປະຈຳ ປີ ພ້ອມ ບົດລາຍງານ ການເງິນ ຫຼັງ ສິ້ນສຸດ ປີ ບັນຊີ. ຈຳນວນ ທີ່ ຊຳລະ ລ່ວງໜ້າ ແລ້ວ
ນຳ ມາ ຫັກ ອອກ ຈາກ ອາກອນ ປະຈຳ ປີ.

| ຂັ້ນຕອນ | ເນື້ອໃນ |
| --- | --- |
| ໃນ ລະຫວ່າງ ປີ | ຊຳລະ ອາກອນ ລ່ວງໜ້າ ຕາມ ງວດ ທີ່ ກຳນົດ |
| ສິ້ນສຸດ ປີ ບັນຊີ | ປິດບັນຊີ ແລະ ຄິດໄລ່ ກຳໄລ ທາງ ອາກອນ |
| ຍື່ນ ໃບແຈ້ງ ປະຈຳ ປີ | ພ້ອມ ບົດລາຍງານ ການເງິນ ທີ່ ຜ່ານ ການ ກວດສອບ |
| ຊຳລະ ສ່ວນ ຕ່າງ | ອາກອນ ປະຈຳ ປີ ຫັກ ອາກອນ ທີ່ ຊຳລະ ລ່ວງໜ້າ |

## ຂາດທຶນ ຍົກ ໄປ ງວດ ຕໍ່ໄປ

ຖ້າ ວິສາຫະກິດ ມີ ຜົນ ຂາດທຶນ ທາງ ອາກອນ, ຂາດທຶນ ນັ້ນ ສາມາດ ຍົກ ໄປ ຫັກ ກັບ ກຳໄລ ຂອງ
ປີ ຕໍ່ໄປ ໄດ້ ພາຍໃນ ຈຳນວນ ປີ ທີ່ ກົດໝາຍ ກຳນົດ, ໂດຍ ຕ້ອງ ມີ ບົດລາຍງານ ການເງິນ ທີ່ ຜ່ານ
ການ ກວດສອບ ຮັບຮອງ ຂາດທຶນ ນັ້ນ.
